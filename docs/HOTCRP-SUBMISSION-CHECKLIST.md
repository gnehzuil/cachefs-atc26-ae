# HotCRP Artifact Submission Checklist

## Required form fields

- [ ] Current paper PDF (<600 MB), title, abstract, authors, affiliations, and emails.
- [ ] Original ACM ATC submission ID: `186`.
- [ ] Topics: `File and storage systems`, `Distributed and parallel systems`; optionally `Deployment experience`.
- [ ] Reproducibility platform: Docker.
- [ ] Badge selection matches released evidence; do not select a badge before public README/home page and license gates are complete.
- [ ] Public stable README URL pinned to a GitHub tag/release.
- [ ] Public stable artifact home page URL (GitHub Pages or organization site), pinned to the same release.
- [ ] Candidate artifact reviewer: author-provided PhD student name/email, or `N/A` if none.
- [ ] PC and other conflicts reviewed by authors.
- [ ] Monitored AE contact address included in README.

## Ready-for-review gate

- [ ] Public release contains scripts/docs only, no private configuration, models, source, or logs.
- [ ] Image digest/release tag/NOTICE/SBOM audit are complete.
- [ ] Real-Qwen two-host P2P/preload results are captured and scoped correctly.
- [ ] Public URLs have been manually tested from a clean session.
- [ ] Authors explicitly authorize HotCRP submission and ready-for-review action.
