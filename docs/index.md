# CacheFS ATC'26 Artifact

This is the public homepage for the CacheFS ATC'26 binary-image artifact.

The artifact uses a fixed public CacheFS image digest, deterministic synthetic data, Docker, FUSE, and either a one-host loopback topology or a user-supplied two-host topology. It validates basic source-backed and peer-served read behavior only.

Start with the [README](../README.md), then review the [image provenance](image-provenance.md), [claims and scope](claims-and-scope.md), and [validation guide](validation.md). An optional [Alibaba Cloud EAS deployment reference](alibaba-cloud-eas-deployment.md) is available for evaluator-managed EAS accounts.
